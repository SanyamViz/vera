2. MAKE IMAGE COMPARISON ACTUALLY FUNCTIONAL
============================================

This is the most important requirement.

Implement a REAL client-side image similarity comparison in JavaScript/React.

No backend.
No external API.
No fake result.
No Math.random().
No hardcoded "97%" / "94%" / etc.

The user must be able to upload:

A. Original product image
B. Suspected copied/stolen image

Then click:

"Compare Images"

The application must actually analyze the two uploaded images in the browser.

Use an average-hash or perceptual-hash style algorithm.

Recommended implementation:

1. Load both uploaded images into HTML Canvas.
2. Resize each image to a small grayscale grid, for example 16x16.
3. Calculate the average grayscale value.
4. Generate a binary hash by comparing each pixel against the average.
5. Compare the two hashes using Hamming distance.
6. Convert the Hamming distance into a similarity percentage.

Formula:

similarity = (1 - hammingDistance / totalHashBits) * 100

Round the result to the nearest whole number.

The result MUST depend on the actual uploaded images.

For example:

* identical images should produce approximately 100%
* resized/cropped/compressed versions should still produce a reasonably high similarity
* clearly different images should produce a much lower similarity

If necessary, use a slightly more robust perceptual hash implementation, but keep it entirely client-side and dependency-light.
